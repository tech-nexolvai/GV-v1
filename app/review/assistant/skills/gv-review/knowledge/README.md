# Knowledge: what a senior millwork reviewer knows

Generic trade knowledge for reading shop drawings against the architect's drawings. Background,
not GV's rules: a GV rule is only what `rules.md` says, and a value is Wrong only against the
architect's printed value, the vendor's own string, or a rule in `rules.md`. Read a file when the
question touches it; a full check's helpers already have theirs in their instructions.

- `glossary.md`: the words and abbreviations on millwork drawings, in plain words.
- `reading-drawings.md`: views (plan, elevation, section), which view governs which number, how
  dimension lines, chains and overalls are drawn.
- `what-dimensions-measure.md`: where each end of a dimension lands (top of counter or underside,
  splash, floor, a box above the unit), with worked examples, and the `spans` words.
- `vendor-mistakes.md`: the usual vendor mistakes, how each looks and how to spot it.
- `field-cut-and-ends.md`: how a countertop meets its walls (three layouts) and when a field cut
  applies.
- `typical-sizes.md`: usual sizes, to catch a misread. Never a reason for Wrong.

GV's own worked examples and approved lessons, when this machine has them, are in `examples/` and
`lessons.md` beside this folder.
