# Typical sizes

**Background only. Never a reason for Wrong.** Use these to catch a misread before code compares (a
counter read as 340" is a slip; a 1/8 read as 1/2 changes a size by 3/8"). A value is Wrong only
against the architect's printed value, the vendor's own string, or a rule in `rules.md`.

| Thing | Usual size | Note |
|---|---|---|
| Kitchen counter height | about 36" AFF | to the top of the top |
| Vanity or bath counter | 30" to 36" AFF | |
| Accessible counter or lavatory | at most 34" AFF | 2010 ADA Standards, sections 606 and 902 |
| Accessible knee clearance | at least 27" high | 2010 ADA Standards, section 606 |
| Base cabinet depth | about 24" | |
| Upper cabinet depth | 12" to 14" | |
| Counter to underside of uppers | 15" to 20" | |
| Toe kick | about 3" deep, about 4" high | |
| Top overhang past the cabinet face | about 3/4" to 1 1/2" | |
| Stone top thickness | 3/4" to 1 1/4" (2 cm or 3 cm) | |
| Laminate top thickness | 1" to 1 1/2" | |
| Backsplash height | about 4" | full-height splashes run to the uppers |
| Filler width | 1" to 3" | GV's limits are in rules.md |
| Door or panel thickness | about 3/4" | |
| Outlet height above a counter | 4" to 8" over the top | AFF to the outlet's centre line |

Sources: 2010 ADA Standards for Accessible Design (U.S. Access Board, chapters 6 and 9); AWI
Architectural Woodwork Standards (general tolerances). Neither is a GV rule: GV compares exactly,
against the architect.
